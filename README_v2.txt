たはらぁめん POS v2
・左：受け渡し管理、右：注文・会計（横向き）
・未提供注文の「詳細を見る」で1杯ごとのトッピングを表示
・詳細の枠内を下にスワイプすると「お渡し済みにする」ボタンを表示
・GitHub Pages上の既存ファイルを上書きして公開します。
・IndexedDBのデータは同じURL・同じブラウザ環境で引き継がれる設計ですが、更新前に必ず管理画面からバックアップJSONを保存してください。
・Service Workerの更新には再読み込み／再起動が必要な場合があります。
・GitHub Pagesは公開URLです。アプリを開いた他人の注文データは端末間で同期しません。
