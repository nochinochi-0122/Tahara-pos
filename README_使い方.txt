たはらぁめんPOS iPad単体・オフライン版 v1
=======================================
【概要】
iPad 1台で注文・会計（左）とお渡し管理（右）を同時表示します。
Windows PC・Pythonサーバー・学校Wi-Fiは営業時に不要です。
ただし、初回インストール時にiPadからHTTPSサイトにアクセスできる必要があります。

【iPadへの導入】
1. このフォルダの全ファイルをHTTPS対応の静的ホスティングにアップロードしてください。
   例：GitHub Pages / Netlify Drop（ファイルを公開するサービス）など。
   GitHub Pages等で公開する場合、アプリ自体はURLを知っている人がアクセスできます。
   注文データやパスワードはiPad内のIndexedDBに保存され、サーバーには送信しません。
2. iPadのSafariでそのHTTPS URLを開き、画面が表示されることを確認します。
3. Safariの共有メニューから「ホーム画面に追加」を選びます。
4. 追加されたアイコンから起動します。初回はオンラインで全ファイルを読み込んでください。
5. 一度オンラインで起動後、機内モードにして再起動し、動作を検証してください。
   iPadOSのバージョンやストレージ状態によってキャッシュが削除される場合があります。

【営業前】
・管理者パスワード（8文字以上）を登録。
・管理 → 営業管理 → 在庫と釣銭準備金の金種を入力して営業開始。
・左側で注文・会計。右側で提供済みへ変更。
・提供直後の取消は直前の操作だけ可能。
・管理 → 売上集計からCSVを書き出せます。
・管理 → バックアップからJSONを「ファイル」アプリに保存してください。

【制約と注意】
・オフラインのiPad1台専用です。他の端末との同期はしません。
・Safariのデータ削除、iPadの故障、アプリの再インストールなどでデータを失う可能性があります。
・30分ごとの自動ファイル保存はiPadのブラウザ制限により行いません。手動で定期バックアップしてください。
・管理者パスワードは端末内にソルト付きSHA-256で保存します。PBKDF2等の強いKDFには未対応です。
・売上CSVはExcelで開きやすいUTF-8 BOM形式です。
・現金とPayPayの着金確認は人が行います。PayPay APIとは接続していません。
・会計画面でPayPay受取額と現金を入力できます。お釣りは現金分のみ計算します。
・同じiPadで使用するため、会計完了画面の間は左側の新規注文を受け付けません。
・日付はiPadの現在日付を使い、注文番号は営業日ごとに001から始まります。
・現行版はローカルブラウザ内の試運転用実装です。営業前に実機テストとバックアップ復元テストを実施してください。
